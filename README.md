# Countdown Timer

A responsive countdown timer built using **HTML5, CSS3, and JavaScript** as part of the **Veda Technology Web Development Internship – Task 13**.

## Overview

This project displays the time remaining until a specified target date, updating the countdown every second. When the countdown reaches zero, a completion message is displayed.

## Features

- Real-time countdown display
- Days, hours, minutes, and seconds
- Configurable target date
- Automatic updates every second
- Completion message when the countdown ends
- Responsive and user-friendly interface

## Technologies Used

- **HTML5** – Structure and content
- **CSS3** – Styling and responsive layout
- **JavaScript** – Date calculations, timer logic, and DOM manipulation

## Key Learning Outcomes

- Working with JavaScript `Date` objects
- Calculating time differences
- Using `setInterval()` and `clearInterval()`
- Updating webpage elements dynamically
- Handling countdown completion

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Configure the target date in the JavaScript code to set your countdown.
